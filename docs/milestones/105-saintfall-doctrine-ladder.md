# 105 — SAINTFALL: Doctrine ladder and single-path Vow

Rework the Field Doctrine board so each Order reads as a ladder, and so
the capstone Vow no longer demands both Tier I rites.

## Rules

- Two T1 rites sit side by side. T2 is a full-width rung under them. T3
  is a full-width rung under T2. The Vow stays the crown of that column.
- Talent cards are compact (name, rank, gate). Detail lives in the
  inspector, which is given the wider column.
- The board must fit the playfield without a page scroll.
- Vow eligibility is **6 points**: one T1 maxed (2) + T2 (2) + T3 (2).
  The second T1 remains optional up to the existing 8-point Order cap.

## Exit

User opens Field Doctrine → sees T1 | T1, then T2, then T3, then the Vow,
with a roomy inspector on the right, no scrolling. Inscribing one T1 path
of six points makes the Vow eligible; the other T1 is still spendable.
