# Rainbot Network UI Refresh — design proposal

Branch: `redesign/ui-refresh`. Non-destructive: `main` is untouched; compare side by side before promoting.

## What the audit found

- **Two competing token layers.** The original brand root (`--bg #080810`, `--accent #ff2e88`, `--accent-2 #2ee0ff`, `--accent-3 #ffd43b`, Bungee/Inter/JetBrains Mono) and a later "arcade portal" root (`--arcade-pink #ff1490`, `--arcade-cyan #23dff2`, `--arcade-yellow #f7d924`, Press Start 2P). Two pinks, two cyans, two yellows, two display fonts — every page mixes them.
- **Six-plus parallel card families** for the same poster+title+meta+CTA job: `.poster-card` (+35 per-slug modifiers), `.directory-card` (+46), `.after-card`, `.after-dark-game`, `.slopwire-card`, `.agent-feature-card`/`.agent-vault-card`, plus `.latest-release-hero/slat` and `.soon-item`. None share a base.
- **Five bespoke heroes** (`.portal-hero`, `.games-hero`, `.after-dark-hero`, `.media-hero`, `.forum-hero`).
- **No mobile nav.** At ≤920px `.nav__links { display:none }` and there is no menu button — Games/Slopwire/TV/Community are unreachable from the nav on phones.
- **Footers drift page to page** (different link sets, community.html stuffs "Community" into the social slot).
- Game-page inline `<style>` blocks are **all page-scoped, per-game namespaced** (`.bsr-page`, `.tls-page`…) with zero cross-file selector duplication — they are per-game stage theming, not shared chrome. Rewriting them is high risk / low reward (many are load-bearing for touch controls and overlays).
- JS coupling to preserve: nav search filters `[data-title]`; `initGamesCatalog()` reads `.directory-card` internals; home panels / profile / leaderboard / game-hub markup is generated by main.js & community.js with its own `rb-*`/`home-*` classes.

## Direction

Same party, cleaned apartment. One palette, one type system, one card, one hero, one footer — with the After Dark line kept deliberately gothic and separate.

### 1. Tokens (extend the original layer; retire the fork)

The original root stays canonical and gains scales. The `--arcade-*` names become **aliases** of the canonical tokens so all the CSS/components not rewritten in this pass (profile modal, leaderboards, community, game hub) harmonize automatically:

```css
:root {
  /* canonical brand (existing, unchanged values) */
  --bg:#05070d; --bg-soft:#0b0e1a; --panel:#0d1020; --panel-2:#171a30;
  --ink:#fbfaf4; --ink-dim:#a9adc4;
  --accent:#ff2e88; --accent-2:#2ee0ff; --accent-3:#ffd43b;
  --good:#6bff7d; --bad:#ff5c5c;
  --font-display:"Bungee",…; --font-body:"Inter",…; --font-mono:"JetBrains Mono",…;
  --font-pixel:"Press Start 2P",…;           /* NEW name for the already-loaded font */
  /* NEW scales */
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-5:24px; --sp-6:32px; --sp-7:48px;
  --text-xs:11px; --text-sm:13px; --text-md:15px; --text-lg:18px;
  --text-xl:clamp(21px,2.2vw,26px); --text-2xl:clamp(28px,3.4vw,40px); --text-3xl:clamp(38px,5vw,60px);
  --r-sm:6px; --r:10px; --r-lg:14px;
  --line:rgba(148,163,199,.16); --line-bright:rgba(148,163,199,.30);
  --shadow:0 6px 0 rgba(0,0,0,.5); --shadow-soft:0 10px 30px rgba(0,0,0,.35);
  --glow-pink:0 0 24px rgba(255,46,136,.25); --glow-cyan:0 0 24px rgba(46,224,255,.22);
  /* aliases — the arcade fork resolves to the brand palette */
  --arcade-pink:var(--accent); --arcade-cyan:var(--accent-2); --arcade-yellow:var(--accent-3); …
}
```

Note `--bg` moves from `#080810` to the arcade `#05070d` — the shade every current page actually renders on; the rest of the legacy values keep working for game pages.

**Font roles** (all four already CDN-loaded; no new deps):
- **Bungee** — display: page titles, panel titles, card titles, buttons. The brand font, restored as the lead voice.
- **Inter** — body copy, descriptions.
- **JetBrains Mono** — nav links, metadata, stats, tickers.
- **Press Start 2P** — tiny arcade accents only (badges, eyebrows, "387 bots online"). No more 10px pixel paragraphs.

### 2. One card: `.rb-card`

```
a.rb-card.rb-card--game            ← poster + meta bar (home featured)
a.rb-card.rb-card--detail          ← + body copy (games.html directory)
a.rb-card.rb-card--dark            ← After Dark: desaturated art, serif title, ember-red hover
a.rb-card.rb-card--article         ← kicker + headline + deck + meta (Slopwire)
a.rb-card.rb-card--video           ← article + play glyph (Rainbot TV)
a.rb-card.rb-card--agent           ← cyan wire look, protocol chips
a.rb-card.rb-card--slat            ← compact horizontal row (recent drops, coming soon)
a.rb-card.rb-card--bare            ← poster only (home After Dark rail)
```

Shared skeleton: `__media` (16:9, `object-fit:cover` default, `--contain`/`--left` utilities), `__badge` (status chip), `__label` (title overlay + standard scrim, only for art without baked titles), `__body` (`__kicker`, `__title`, `__desc`), `__meta` (category **b** / detail **em** + play chevron). The 80+ per-slug poster modifiers collapse into these utilities. Hover: lift + pink border + glow (cyan for agent, red for dark).

### 3. One hero: `.rb-hero`

One grid skeleton (copy + media/aside, eyebrow, title, sub, actions, ticker) with per-page modifiers: `--home` (mascot sticker art), `--games`, `--media` (newsroom/TV art), `--forum`, `--agent`, `--dark` (full-bleed hero art, serif). Existing art reused as-is, cropped via CSS only.

### 4. Consistent chrome

- **Nav** (main.js `renderNav`): same brand PNG, mono links, compact search, Pro/Login — plus a **real mobile menu** (hamburger → dropdown panel) so phone users can actually navigate. Active link = pink underline (kept).
- **Footer**: one canonical markup on all shell pages — brand + tagline, three link groups (Play / Watch & Read / Fine Print), social row, parody disclaimer.
- **Panels**: keep `.arcade-panel`/`.arcade-panel__header` skeleton (it's already consistent) restyled on tokens: Bungee panel titles, roomier padding, consistent 24px section rhythm, radius `--r-lg`.
- **Buttons**: `.arcade-btn` keeps its API (`--primary/--outline/--cyan/--yellow`), restyled in Bungee with consistent sizes (`--sm` added). Legacy `.btn` untouched (game pages depend on it).
- **Badges/chips**: `.rb-badge` (pixel, for status) and `.rb-chip` (mono, for filters/tags) replace the six ad-hoc treatments.

### 5. After Dark stays its own thing

`body.theme-afterdark` (after-dark.html): near-black `#050308` background, no neon grid overlay, Georgia/serif display (the same face the AGAIN. line uses in-game), desaturated posters that resaturate on hover, ember-red `#7a1f1f` borders/accents (the established After Dark red), pink reserved for one CTA. Cards on the main site that belong to the line get `.rb-card--dark` so the contrast reads *inside* the arcade too. The Last Signal keeps its serious sci-fi poster treatment — no meme styling applied.

## Scope guardrails (unchanged from brief)

- No art regenerated; crops via CSS only.
- `games/*.html` canvases, HUDs, and `assets/js/<slug>.js` untouched. Game pages inherit the new nav automatically (markup comes from main.js); their per-game inline styles stay (audited: they're gameplay chrome, not duplicated site chrome — see above).
- Static site: no build step, no new deps.
- JS updated only where markup demands it: `renderNav` (mobile menu), `initGamesCatalog` selectors (new card classes), games-section header markup.

## CSS lifecycle

New system appended as a clearly-marked `RB-UI` layer in styles.css; the six card families + five heroes are deleted once every reference is rewritten (verified by grep); legacy game-page styles (`.game-page`, `.canvas-wrap`, `.btn`, overlays, touch pads, modals, toasts) stay byte-compatible. Cache-buster bumped to `?v=20260702-uiredesign-1` on touched pages.
