# Scrap Circuit AI Texture Sources

These atlases were generated with the built-in image generation tool, then cropped, color-variant processed, pixelated, and quantized into the 80 manifest textures under `assets/textures/scrap-circuit/`.

- `ai-environment-material-atlas.png`: source swatches for arena terrain, structures, props, and cemetery/boardwalk/rooftop materials.
- `ai-vehicle-material-atlas.png`: source swatches for vehicle paint, glass, rubber, metal, decals, bone, rust, and special materials.
