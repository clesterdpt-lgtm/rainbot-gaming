Tardigrade Micro Mayhem texture assets
======================================

These SVG texture tiles were created for the Rainbot Gaming tardigrade prototype.
They are project-authored, attribution-safe browser game assets and may be treated
as CC0-1.0 within this project. They are not copied from the user-provided
inspiration images.

Runtime use:
- `micro-floor-speckles.svg` repeats across the petri dish floor.
- `algae-cell-tile.svg` gives collectible algae a chunky cell texture.
- `membrane-strands.svg` adds simple low-poly strand detail to teal fibers.
